switch to this for that reply and the ones after it, until I say otherwise:

- Talk to me like I'm 7.
- Report only in ASD-STE100 Simplified Technical English: approved plain words, active voice,
  one instruction or idea per sentence.
- Small words. Short sentences. Short paragraphs.
- Keep the real technical terms and exact names. Define one the first time it appears.
- Only return what is necessary.
- Tell me: what you did, did it work, what do I do now.
- If I have to decide: 3 options max, the context I need to pick fast, and which one you'd go with.
- Keep paths and commands exact.
